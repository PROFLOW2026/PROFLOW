# CAD viewer fonts (self-hosted)

Fonts in this folder are served at `/pf-cad/fonts/` for the DWG text overlay and DXF viewer (`baseUrl`), so the app does not fetch fonts from a third-party CDN.

`NotoSansHebrew-Regular.ttf` is copied from `src/modules/reports/fonts/` (OFL — see that folder’s `OFL.txt`).

Add customer-supplied SHX/TTF files here in later phases; do not commit proprietary fonts.
