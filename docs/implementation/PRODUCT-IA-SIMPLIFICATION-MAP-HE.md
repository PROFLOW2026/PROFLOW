# מפת מבנה מידע — מצב נוכחי מול המלצה

היקף: מוצר מחובר בלבד (לא דף בית ציבורי).

## מצב נוכחי (תמצית)

### ניווט ראשי (מובייל)

1. לוח בקרה  
2. פרויקטים  
3. הוצאות  
4. עוד → כמעט כל שאר המודולים באותה רמה  

### ניווט שולחני

רשימה ארוכה: ליבה + CRM + רכש + שטח + נכסים + ציות + מסמכים + הגדרות…

### בתוך פרויקט

טאבים: סקירה · כספים · הוצאות · שינויים · חיובים · עבודה · שעות · מסמכים · פרטים  

### הגדרות

~15 פריטים שטוחים (עסק, אנשים, תפקידים, יכולות, קטגוריות, קטלוג, מס, פעילות, פרופיל, תבניות, שדות, API, פורטל, אפליקציה, אופליין…)

### בעיה

הכל נראה חשוב באותה מידה.  
מודול מתקדם (AP, API, פורטל, OCR חלקי) מתחרה בליבה (פרויקט / הוצאה / חיוב).

## מבנה מומלץ

### CORE — תמיד זמין (אחרי הקמה)

| אזור | למה |
|------|-----|
| לוח בקרה | לאן ללכת היום |
| פרויקטים (+ סביבת פרויקט) | לב העסק |
| הוצאות | עלות בפועל |
| לקוחות | מי משלם |
| שינויים ותוספות | עדכון חוזה |
| חיובים וגבייה | כסף שנכנס |
| דוחות (+ ייצוא) | תמונה כוללת |
| הגדרות בסיס | עסק, אנשים, פרופיל, מס, אפליקציה |

**בתוך פרויקט (CORE tabs):** סקירה · כספים · הוצאות · שינויים · חיובים · פרטים  

### OPTIONAL — נדלק ביכולות / כשצריך

| אזור | למה |
|------|-----|
| מכירות (CRM) | לפני פרויקט |
| ספקים | כשיש ספקים קבועים |
| עובדים ושעות | כוח אדם |
| רכש + RFQ | התחייבויות רכש |
| קטלוג חומרים | מחירונים |
| עבודה בשטח | יומנים / תיקונים / בדיקות |
| ביטוחים וציות | תוקפים |
| מסמכים (צירוף) | קבצים לרשומות |
| קטגוריות עלות / תבניות | ארגון |

**טאבים אופציונליים בפרויקט:** שעות · מסמכים · קישור לשטח  

### ADVANCED — מאחורי «מתקדם» / לא ב־More הראשי

| אזור | למה |
|------|-----|
| חשבונות ספקים (AP) + התאמות | מומחיות הנה״ח |
| מלאי | מלאי תפעולי ≠ הנה״ח |
| צי רכב + תחזוקה | ציוד |
| ייבוא נתונים | חד־פעמי / IT |
| שדות מותאמים | מנהל מערכת |
| קטלוג מתקדם (DSL שכר) | מומחה |
| יומן פעילות | ביקורת |
| יכולות (הפעלת מודולים) | מנהל |

### INTERNAL — לא ללקוח רגיל

| אזור | למה |
|------|-----|
| API ו־webhooks | מפתחים |
| פורטל פנימי / תצוגות QA | עד פורטל ציבורי אמיתי |
| `/setup` + משתני סביבה | התקנה מקומית |
| OCR fixture / stub / מפתחות סביבה | בדיקות |
| חילוץ OCR כלקוח | **רק אחרי ספק אמיתי** (או מצב «בדיקה» מפורש) |
