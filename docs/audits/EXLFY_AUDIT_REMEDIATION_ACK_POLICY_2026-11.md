# תיקון מדיניות אישור אזהרת כפילות

המדיניות `duplicate_warning_acknowledgements_ack` מתעדכנת רק שורה במצב `pending` שהמאשר שלה ריק.

- השארה ב-`pending` מותרת, בלי מאשר ובלי תאריך אישור. שמירה חוזרת נשארת תקינה.
- מעבר ל-`acknowledged` מותר רק כש-`approver_user_id = app.current_user_id()`.
- שורה שכבר אושרה לא נראית לעדכון, ולכן אי אפשר להחזיר אותה ל-`pending` ואי אפשר להחליף את המאשר.
- שינוי snapshot יוצר שורה חדשה לפי ה-hash. האישור הישן לא נכתב מחדש. הקוד גם לא מעדכן בשמירה חוזרת שורה שכבר אושרה.

## בדיקת RLS

| בדיקה | תוצאה |

| שמירה חוזרת של pending | עברה |
| משתמש א׳ מאשר בשם משתמש ב׳ | נדחה, 42501 |
| משתמש א׳ מאשר בתור המשתמש הנוכחי | עברה |
| החזרת אזהרה מאושרת ל-pending | לא שינתה את השורה |
