**מקורות מסלול קיימים (site map):** `/sign-up` · `/sign-in` · `/onboarding` · `/setup` · Dashboard `/`

## 2. «התחילו עכשיו» — זרימה מומלצת

```text
דף נחיתה
  → /he-IL/sign-up
    → אימות חשבון / אימייל (כפי שקיים במוצר)
      → /he-IL/onboarding
        → /he-IL/setup (הגדרת העסק)
          → לוח בקרה /
```

### כללים
- אחרי הרשמה מוצלחת — **לא** להחזיר לדף השיווקי.  
- אם המשתמש כבר מחובר ולוחץ CTA — לנתב ישר ללוח בקרה / setup לפי מצב הארגון.  
- שמור `?from=landing` אופציונלי לאנליטיקה בלבד.  
- אין בחירת תמחור חובה בדרך.

### מצבי קצה
| מצב | התנהגות |
|-----|---------|
| כבר יש חשבון | קישור «כניסה» ב־Hero/Header → `/sign-in` → אחרי login ל־`/` או setup |
| נטש באמצע onboarding | בחזרה ל־onboarding/setup לא לדף שיווק |
| שגיאת הרשמה | הודעה על מסך sign-up; לא לאבד הקשר |

## 3. «ראו איך זה עובד» — המלצה נוכחית

**התנהגות מומלצת עכשיו:**  
גלילה חלקה לעוגן `#product-tour` (סקציית סיור צילומי מסך).

| אפשרות | מתי |
|--------|-----|
| **A. Scroll to tour** ← ברירת מחדל | אין וידאו עדיין; צילומים אמיתיים מספיקים |
| B. Guided demo section | אותו עוגן + טאבים מודגשים |
| C. Short video | רק אחרי שיש סרטון עברי קצר (60–90 שנ׳) — אז המשני יכול לפתוח מודאל וידאו *או* לגלול ל־tour+וידאו |

**לא מומלץ כרגע:** מעבר ל־YouTube חיצוני כברירת מחדל · סיור מוצר מאומת שדורש login.

---

## 4. «בקשו הדגמה» (אופציונלי)

- מיקום: CTA סופי בלבד (לא Hero).  
- פעולה: טופס קצר (שם, טלפון/אימייל, סוג עסק) או `mailto:`.  
- לא להחליף את «התחילו עכשיו».

---

## 5. התקנה כאפליקציה

מסקציית מובייל:

1. הסבר קצר: התקנה מהדפדפן; Android ישיר כשנתמך; iOS = הוסף למסך הבית.  
2. לא לחנות.  
3. אופציה: קישור לעמוד עזרה ציבורי קצר **או** אחרי login ל־`/settings/app`.  
4. משתמש חדש: עדיף קודם «התחילו עכשיו»; התקנה אחרי שיש חשבון — או CTA התקנה ציבורי על auth shell (קיים לפי site map).
